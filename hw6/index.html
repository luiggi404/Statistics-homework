HW6 — Riemann vs Lebesgue integration, and the normal CDF

Exercise 1 computes the same integrals by slicing the domain (Riemann) and by slicing the range (Lebesgue), and compares accuracy, convergence and cost, down to the Dirichlet and Thomae functions. Exercise 2 builds an efficient, double-precision method for the standard normal CDF Φ, checks it against published reference values, and explains why Φ needs special functions and numerics at all.

Why these two belong together. A cumulative distribution function is an integral: Φ(x) = ∫−∞x φ(t) dt, and in general P(X ∈ A) = ∫A f. Probability theory is built on the Lebesgue integral (an expectation is a Lebesgue integral with respect to a probability measure), while every number we actually print comes from a finite computation. Exercise 1 is about which integral and how to approximate it; Exercise 2 is the most important integral in statistics that has no closed form.

Exercise 1 — Riemann and Lebesgue integration

1.1 Two ways to slice an area

Riemann sum. Partition the domain [a, b] into N cells [xi−1, xi] of width h = (b − a)/N, pick a tag ξi in each cell, and add up rectangles: SN = Σ f(ξi)·h. The function is Riemann-integrable when every choice of tags gives the same limit as h → 0, equivalently when the upper and lower Darboux sums (sup and inf of f on each cell) have the same limit.
left: ξi = xi−1 midpoint: ξi = (xi−1 + xi)/2 right: ξi = xi
Lebesgue sum. Partition the range of f into levels y0 < y1 < … < yK, and for each band look at its preimage Ej = {x : yj ≤ f(x) < yj+1} — the set of points, wherever they are in the domain, at which f falls in that band. Its measure μ(Ej) generalises length (for an interval, its length; for a union of disjoint intervals, the sum of lengths; for a countable set, 0). The integral of the simple function φ = Σ yj·1Ej is Σ yj·μ(Ej), and the Lebesgue integral of f is the limit as the bands shrink.

Lebesgue's own analogy: Riemann counts coins in the order they come out of the purse; Lebesgue first sorts them by value and then counts how many there are of each. Grouping the terms by value gives two sums that bracket the integral. With Δ = yj − yj−1 constant and summing by parts:

lower φ = largest level ≤ f : LK = y0·|D| + Σj=1..K Δ · μ{ f ≥ yj } upper ψ = smallest level ≥ f: UK = y0·|D| + Σj=1..K Δ · μ{ f > yj−1 } LK ≤ ∫ f ≤ UK, UK − LK ≤ Δ·|D| for every bounded measurable f

The bound does not depend on how wild f is — continuity, jumps, oscillation do not enter — only on the level spacing. This is the theoretical advantage of slicing the range. Its price is that we need the measure of the sets {f ≥ t}, i.e. the distribution function m(t) = μ{f ≥ t}. In fact LK and UK are the lower and upper Riemann sums of the "layer cake" formula ∫ f = y0·|D| + ∫y0∞ m(t) dt, and their average is the trapezoid rule applied to m. That is the estimate we call Lebesgue (mid) below.

1.2 How a Lebesgue sum is computed numerically

For the textbook functions m(t) is known in closed form (for sin on [0, π], μ{sin x ≥ t} = π − 2 arcsin t), but a general method cannot assume that. Here the preimage is found numerically, the same way for every function:

  1. Evaluate f once on a bracketing grid of G cells (default G = 1000), cached and reused for all levels.
  2. For a level t, a cell whose two endpoints are both ≥ t counts whole, both < t counts zero.
  3. A cell whose endpoints disagree contains a boundary of the preimage: locate it by bisection on the predicate f(x) ≥ t, to 10−13 of the cell width, and add the part of the cell on the correct side.
function measure(t) {                    // μ{ x : f(x) ≥ t }
  let m = 0;
  for (let i = 0; i < G; i++) {
    const pa = ys[i] >= t, pb = ys[i+1] >= t;
    if (pa && pb) { m += w; continue; }
    if (!pa && !pb) continue;
    let lo = xs[i], hi = xs[i+1];
    while (hi - lo > 1e-13 * w) { const c = (lo+hi)/2; if ((f(c) >= t) === pa) lo = c; else hi = c; }
    m += pa ? lo - xs[i] : xs[i+1] - lo;
  }
  return m;
}

Two consequences that the experiments will show. A jump of f is located to machine precision by the bisection, wherever it is — a grid that does not contain the jump point does not matter. But an excursion of f above t that starts and ends inside one grid cell is invisible: the method needs to see every boundary of the preimage at the grid resolution.

Unbounded functions. For 1/√x the range [1, ∞) cannot be cut into finitely many equal bands. The sums are applied to the truncation min(f, Y), and Y grows with K: ∫ min(f, Y) ↑ ∫ f by the monotone convergence theorem, which is exactly how the Lebesgue integral of an unbounded function is defined. The band error is about Δ = Y/K and the truncation error is ∫Y∞ m(t) dt = 1/Y for 1/√x; balancing the two gives Y ≈ √K, which is used here (Y = 1 + √K).

1.6 Where the two approaches behave differently

For every Riemann-integrable function in the list both approaches converge to the same value, the exact integral — as theory requires, since a Riemann-integrable function is Lebesgue-integrable with the same integral. What differs is how they get there, and the differences are systematic:

  • Smooth functions (sin x, x², sin x/x): Riemann midpoint is second order, error ∝ N−2. Lebesgue mid is only of order K−3/2, and Lebesgue lower/upper of order K−1. The reason is in the range, not the domain: where f′ = 0 (the top of sin, the bottom of x² at 0, the top of sin x/x at 0) f is flat, so a thin band of values has a wide preimage and m(t) has a square-root singularity, m(t) ≈ c·√(tmax − t). Riemann has trouble where f is steep; Lebesgue where f is flat.
  • Piecewise-linear |x − ½|: both are exact up to rounding at every N, K — Riemann midpoint because the function is linear on each cell (the grid puts ½ on a cell edge for even N), Lebesgue mid because m(t) = 1 − 2t is linear, so the trapezoid rule on it is exact.
  • Jumps (the two step functions): Riemann is exact only when the jump at ½ falls on a cell edge (even N). For odd N the cell containing the jump is wrong by the size of the jump: the error is jump·h/2 ∝ 1/N, see the table. Lebesgue does not care where the jump is: the step function takes two values, every preimage is [0, ½) or [½, 1], bisection finds ½ to machine precision, and the sum is exact for any K.
  • Unbounded 1/√x: the Riemann left sum is undefined (f(0) = ∞) and the integral is an improper Riemann integral, a limit of proper ones. Midpoint and right sums converge, slowly (∝ N−1/2). For Lebesgue the function is simply integrable — no special definition needed — and monotone convergence gives the computation; numerically it is just as slow (∝ K−1/2) because the area hides in the tall, thin spike near 0.
  • Oscillating sin(1/x): here the numerical Lebesgue sum stalls. Near 0 the function crosses every level infinitely often; crossings closer than one grid cell are missed, and refining the levels does not help — only refining G does (try G = 10 000 in §1.4). Riemann midpoint keeps improving with N because its samples, though aliased near 0, average out. A theoretical advantage (the range-side bound Δ·|D|) is only as good as our ability to compute the measure of the preimages.

Cost. Per estimate, Riemann needs N evaluations. Lebesgue needs G evaluations for the grid plus about 44 bisection steps for every preimage boundary at every level, so for a smooth function with c crossings per level it costs about G + 88·c·K evaluations, roughly 90–180 times more for the same N = K, and its error per evaluation is worse. On a computer the expensive part of the Lebesgue integral is not the sum, it is inverting f.

1.7 Pathological functions

These cannot be evaluated in floating point at all: every IEEE-754 double is a rational number m·2e, so "is x rational?" is always true for a computer number. They are therefore handled with exact arithmetic: sample points are fractions p/q with integer p, q, or points known to be irrational by construction (a rational plus √2/(10N), irrational because √2 is).

Lebesgue's criterion. A bounded function on [a, b] is Riemann-integrable if and only if the set of its discontinuities has measure zero. It explains both examples below at once.

Dirichlet function: 1 on rationals, 0 on irrationals

Riemann. Every cell, however small, contains both rationals and irrationals, so every upper Darboux sum is 1 and every lower one is 0, for every N: the sums do not converge to a common value, and the answer depends on whether the tags happen to be rational. f is discontinuous at every point (measure 1), so by Lebesgue's criterion it is not Riemann-integrable.

Lebesgue. f takes two values, so two levels suffice: ∫ f = 1·μ(ℚ ∩ [0, 1]) + 0·μ(irrationals) = μ(ℚ ∩ [0, 1]). The rationals are countable: list them r1, r2, … (by denominator, as in the Farey sequence) and cover rk by an interval of length ε/2k. The cover has total length ≤ ε, for every ε > 0, hence μ(ℚ ∩ [0, 1]) = 0 and ∫ f = 0.

denominators up to Qε =

Monte Carlo in floats. The natural numerical counterpart of the Lebesgue view is to sample x uniformly: a truly random real is irrational with probability 1, so the estimate is 0. A computer's random number is not: Math.random() returns k/253, and a correct rationality test answers "rational" every time.

The distinction between ℚ and the irrationals is invisible to sampling; it lives entirely in the measure. That is why the Dirichlet function is an argument about definitions, not something one can approximate numerically.

Thomae function: 1/q at x = p/q in lowest terms, 0 at irrationals

Thomae's function is continuous at every irrational (near an irrational, all fractions have large denominators) and discontinuous at every rational (f(p/q) = 1/q, but irrationals arbitrarily close give 0). The discontinuities are countable, measure zero, so it is Riemann-integrable, with integral 0 (the lower sums are all 0). Here the sums can be computed exactly:

rational tags k/N: SN = (1/N)·Σk=1..N 1/(N / gcd(k, N)) = Σk gcd(k, N) / N² upper Darboux sum: UN = (1/N)·Σk 1/qmin(k), qmin(k) = smallest q with some p/q in [k/N, (k+1)/N]

Lebesgue. For any levels, f ≥ yj > 0 holds only at the finitely many fractions with q ≤ 1/yj: every preimage above level 0 is finite, of measure 0. So LK = UK = 0 for every K: the Lebesgue sums are exact from the first step, while the Riemann sums creep towards 0 at a rate that depends on the arithmetic of N.

1.8 Conclusions for Exercise 1

  • Same limit. On every Riemann-integrable example the Riemann and Lebesgue estimates converge to the same, exact value. The two theories agree wherever Riemann's is defined; Lebesgue's extends it (Dirichlet) and handles unbounded functions and limits (monotone convergence) without special cases.
  • Accuracy and convergence. Riemann's error is governed by the regularity of f in x (midpoint: N−2 for smooth f, N−1 with a misplaced jump). Lebesgue's is governed by the regularity of the distribution function m(t) = μ{f ≥ t}: exact for step functions wherever the jump is, K−3/2 for smooth f because of flat spots, and a uniform worst-case bound Δ·|D| that makes LK, UK a certified bracket.
  • Efficiency. Riemann is far cheaper: N evaluations, embarrassingly simple. A practical Lebesgue sum must compute the measure of preimages, i.e. solve f(x) = t over and over; with a bracketing grid and bisection it costs one to two orders of magnitude more evaluations, and it can be fooled by oscillations finer than the grid.
  • Why Lebesgue anyway. Its strength is theoretical: integrals of limits (monotone and dominated convergence), integrals over arbitrary measurable sets, and integration with respect to any measure — which is exactly what probability needs (E[X] = ∫ X dP, P(X ∈ A) = ∫A f). In numerical practice, its idea survives as "integrate the distribution of values": Monte Carlo, quantile methods, and the layer-cake formula E[X] = ∫0∞ P(X > t) dt for X ≥ 0.

Exercise 2 — Numerical computation of the normal CDF

2.1 The object

Definition. The standard normal density is φ(t) = e−t²/2/√(2π), and its cumulative distribution function is Φ(x) = P(Z ≤ x) = ∫−∞x φ(t) dt. By symmetry Φ(−x) = 1 − Φ(x) and Φ(0) = ½, so Φ(x) = ½ + ∫0x φ(t) dt. The upper tail Q(x) = 1 − Φ(x) = Φ(−x) is what p-values need. Any normal X ~ N(μ, σ²) reduces to it: P(X ≤ x) = Φ((x − μ)/σ).

That φ integrates to 1 is shown by squaring the integral and moving to polar coordinates (Hogg–McKean–Craig §3.4). The trick works for the integral over the whole line only; it says nothing about ∫0x, which is the next point.

2.2 Why Φ is not an elementary function: Liouville's theorem

Elementary function. A function obtained from x and constants by finitely many arithmetic operations, compositions, exponentials, logarithms and roots of polynomial equations (trigonometric functions and their inverses are included, through complex exponentials and logarithms). The question is whether ∫ e−t²/2 dt is one of these.

Liouville's theorem (1835), in the form for f·eg. Let f and g be rational functions, g not constant. Then ∫ f(x)·eg(x) dx is an elementary function if and only if there is a rational function R such that

R′(x) + g′(x)·R(x) = f(x), and then ∫ f·eg dx = R·eg + C.

The general theorem (Liouville; made rigorous in differential algebra by Ritt and Rosenlicht) says that an elementary antiderivative, if it exists, can only be the integrand's own field plus logarithms; specialised to f·eg, everything except R·eg must cancel. For the Gaussian, f = 1 and g = −x²/2, so g′ = −x, and the question becomes: is there a rational R with

R′(x) − x·R(x) = 1 ?
  1. R has no poles. Suppose R has a pole of order k ≥ 1 at some point a. Then R′ has a pole of order k + 1 at a, while x·R has a pole of order at most k there, and the right-hand side 1 has none. The term of order k + 1 cannot be cancelled: contradiction. So R is a polynomial.
  2. R is not a polynomial. If R ≠ 0 has degree d, then x·R has degree d + 1 and R′ degree d − 1, so R′ − x·R has degree d + 1 ≥ 1 and cannot equal the constant 1. And R = 0 gives 0 ≠ 1.

No such R exists, so e−x²/2 has no elementary antiderivative. Since Φ′ = φ, Φ would be one: Φ is not elementary. The same argument with g = −x² covers ∫ e−t². The Hogg–McKean–Craig notes cite exactly this result (Liouville, Rosenlicht) and then give the antiderivative as a power series instead.

2.3 The error function: an exact formula that still has to be computed

Definition. The error function is erf(z) = (2/√π)·∫0z e−s² ds, an odd function with erf(∞) = 1; erfc = 1 − erf is its complement. Substituting t = s√2 gives the exact identity
Φ(x) = ½ · [ 1 + erf(x/√2) ], Q(x) = ½ · erfc(x/√2)

When an important integral has no elementary antiderivative, mathematics gives it a name and studies it as a new function — exactly as log is the name of ∫ dt/t. Once named, erf is an exact analytical object: it has a Taylor series that converges everywhere (it is entire), a known asymptotic expansion and continued fraction, a derivative, symmetries, an inverse (used for normal quantiles), and relations to other special functions (erf(z) = P(½, z²), the regularised incomplete gamma function). Formulas like the one above are exact, can be differentiated, inverted and manipulated symbolically.

But a name is not a number. To print erf(0.7) someone must still run an algorithm, just as for sin or exp. JavaScript does not even have Math.erf; C's erf exists, but inside the math library it is evaluated by piecewise rational approximations and exponentials, i.e. by numerical methods of the kind below. The special function moves the problem from "find a formula" (impossible, by Liouville) to "evaluate a known function fast and to full precision" — a numerical-analysis problem with several good answers.

2.4 The numerical methods

(a) Numerical integration. Φ(x) = ½ + ∫0|x| φ (with the sign of x), by the composite trapezoid rule (error O(h²)) or Simpson's rule (error O(h⁴)) on n panels. Simple and general, but the cost grows with the accuracy wanted and with |x|.

(b) Series of erf. Integrating the exponential series term by term:

erf(z) = (2/√π) · Σk≥0 (−1)k z2k+1 / ( k! (2k+1) )

It converges for every z, but it alternates, and for large z the terms grow huge before they shrink (at z = 8/√2 the largest is ≈ 5·1011) while the sum is ≈ 1: catastrophic cancellation, as in HW5, leaves only a few correct digits. Multiplying by e−x²/2 first removes the alternation (Marsaglia's series):

Φ(x) = ½ + φ(x) · ( x + x³/3 + x⁵/(3·5) + x⁷/(3·5·7) + … ) all terms of one sign

This is accurate to the last bit for |x| up to about 3; beyond that it needs many terms and, in the lower tail, Φ = ½ − (something ≈ ½) cancels again.

(c) Continued fraction for the tail (Laplace), convergent for x > 0 and fast exactly when the series is slow:

Q(x) = 1 − Φ(x) = φ(x) / ( x + 1/( x + 2/( x + 3/( x + … ))))

It returns the tail Q directly, so Φ(−x) = Q(x) keeps full relative accuracy even at Φ(−37) ≈ 6·10−300. It is evaluated with the modified Lentz algorithm, stopping when the next factor changes the value by less than 10−16.

(d) Closed-form approximations. Abramowitz & Stegun 26.2.17: Q(x) ≈ φ(x)·(b1t + … + b5t⁵), t = 1/(1 + 0.2316419 x), absolute error < 7.5·10−8, five multiply-adds. Pólya (1949): Φ(x) ≈ ½(1 + √(1 − e−2x²/π)), error < 0.003: a single formula, good enough for a sketch.

(e) The method proposed here. Combine the two exact expansions where each is at its best:

|x| < 3 : Marsaglia's series (≤ 32 terms, all positive) |x| ≥ 3 : Laplace continued fraction for Q(|x|) (≤ 52 terms), then Φ(x) = Q(−x) or 1 − Q(x)
function Phi(x) {
  const phi = Math.exp(-x*x/2) / Math.sqrt(2*Math.PI);
  if (Math.abs(x) < 3) {                       // centre: series with positive terms
    let t = x, s = x;
    for (let k = 1; ; k++) { t *= x*x/(2*k+1); if (s + t === s) break; s += t; }
    return 0.5 + phi * s;
  }
  const a = Math.abs(x);                        // tails: Laplace continued fraction (Lentz)
  let f = a, C = a, D = 0;
  for (let k = 1; k < 5000; k++) {
    D = 1 / (a + k*D); C = a + k/C; const d = C*D; f *= d;
    if (Math.abs(d - 1) < 1e-16) break;
  }
  const Q = phi / f;
  return x > 0 ? 1 - Q : Q;
}

The switch at 3 balances the two term counts (series 32, fraction 52) and keeps the series where 1 − Φ is still ≥ 1.3·10−3. Both pieces have a mathematically exact limit; truncation is stopped when the next term no longer changes the double, so the accuracy is set by rounding, not by an approximation formula.

2.8 Conclusions for Exercise 2

  • Why numerics. By Liouville's theorem e−x²/2 has no elementary antiderivative, so Φ has no closed form in elementary functions. The error function gives an exact representation, Φ(x) = ½[1 + erf(x/√2)], useful for analysis, but erf is itself evaluated by series, continued fractions or rational approximations.
  • Integration works and converges at the predicted rates (trapezoid h², Simpson h⁴), but is the most expensive way to reach full precision, and as an absolute-error method it is useless deep in the tail.
  • Series: the alternating erf series loses digits to cancellation as |x| grows (about 4 correct digits at x = 8). Marsaglia's positive series is exact to rounding in the centre. Neither can give small lower-tail probabilities with relative accuracy, because they compute ½ − (≈ ½).
  • The continued fraction is the right tool for the tails and gives Q(x) with full relative precision down to the smallest doubles. Slow near 0 (hundreds of terms at |x| = 1), which is why it is paired with the series.
  • The hybrid method (Marsaglia for |x| < 3, continued fraction for |x| ≥ 3) reproduces all 15 published decimals of the reference table in 13 of 14 rows (at k = 2 the 15th decimal is off by one: Φ(2) is computed 1 unit in the last place too low, and 2Φ − 1 shows it), and agrees with 40-digit mpmath to within a few units in the last place, in both absolute error on Φ and relative error on the tails, with at most about 50 terms.
  • Closed-form approximations are the fastest; A&S 26.2.17 delivers its advertised 7.5·10−8, enough for tables and most applied statistics, but not for tiny p-values (relative error grows in the tail). Pólya's one-liner is fine for intuition only.
